1. 적용 범위와 처리 원칙

이 방침은 하나가계부 앱과 운영자에게 보내는 문의에 적용됩니다. 앱은 별도의 하나가계부 회원가입 없이 사용할 수 있습니다. Google 계정 연결은 사용자가 Drive 백업을 이용하기 위해 선택하는 절차입니다.

운영자는 사용자의 가계부 정보를 광고나 판매 목적으로 이용하지 않습니다. 앱에는 광고 표시 또는 사용자 행동 분석을 위한 SDK를 포함하지 않습니다. 사용자가 문의 과정에서 직접 제공한 정보를 제외하면 운영자가 기기나 사용자 Drive에 저장된 가계부를 원격으로 열람하는 기능은 없습니다.

2. 처리하는 정보와 목적

사용자가 입력하는 가계부 정보

수입·지출의 금액, 날짜, 분류, 결제수단, 메모, 자산·계좌 이름과 금융기관 표시명, 통화, 잔액, 거래 내역, 정기 거래 및 할부 설정을 기기에 저장합니다. 가계부 기록, 조회, 통계, 일정 계산과 백업·복원에 이용합니다. 은행 계좌나 카드사의 거래 내역을 금융기관에서 직접 조회하지 않습니다.

앱 설정과 기능 상태

테마, 글꼴·글자 크기, 월 시작일, 자동 기록 사용 여부, 사용자가 선택한 알림 앱의 이름·패키지 식별자, 등록한 SMS 발신번호·표시 이름·결제수단 연결, 백업 설정·처리 시각·오류 상태를 기기에 보관합니다. 선택한 기능과 화면 설정을 유지하고 중복 기록 및 백업 오류를 처리하는 데 이용합니다.

SMS·알림에서 읽는 정보

선택한 앱의 알림 제목·본문·발생 시각·앱 식별자와 등록한 발신번호에서 온 새 SMS의 발신번호·본문·발송 및 수신 시각을 처리합니다. 결제금액, 거래일, 가맹점을 해석하여 가계부에 기록하고, 중복 여부나 사용자의 확인이 필요한 내역을 구분하는 데 이용합니다. 메시지 원문에는 해당 발신자가 기재한 이름이나 카드 식별정보 등이 포함될 수 있습니다.

Drive 연결 및 백업 관리 정보

Google이 제공하는 연결 계정의 이메일 주소를 기기에 저장해 연결 계정을 표시하고, 같은 계정의 백업을 이용합니다. Google 인증 과정에서 받은 접근 토큰은 Drive 요청에 이용하며 앱 자체 파일이나 운영자 서버에 저장하지 않습니다. Google 계정의 비밀번호를 앱이 입력받거나 보관하지 않습니다.

백업 구분과 복원을 위해 앱이 임의로 생성한 기기 구분값, 기기 모델명, 백업 파일명·생성 시각·크기·검증값, 암호화 키를 구분하는 값 등을 처리합니다. 기기 구분값은 앱이 생성한 임의의 값이며 IMEI·전화번호와 같은 하드웨어 식별자가 아닙니다.

문의 이메일

사용자가 문의할 때 발신 이메일 주소, 메일에 표시된 이름, 문의 내용, 사용자가 첨부한 자료 및 답변 기록을 운영자가 처리합니다. 문의 답변, 오류 확인 및 개인정보 관련 요청 처리에만 이용합니다.

3. SMS·알림 자동 기록

SMS와 푸시 알림 자동 기록은 각각 기본적으로 꺼져 있습니다. 해당 기능을 켜고 필요한 기기 권한을 허용한 뒤 대상 발신번호 또는 앱을 선택하면, 앱 화면을 열지 않은 동안에도 새로 도착한 결제 메시지를 처리할 수 있습니다.

  • SMS 수신 권한: Android에서 전달받은 새 SMS의 발신번호를 확인하여 등록한 번호의 결제 문자를 처리합니다. 기존 문자함을 조회하거나 문자를 보내지 않으며, 연락처를 읽지 않습니다. 등록하지 않은 번호의 문자는 보관하지 않습니다.
  • 알림 접근 권한: 사용자가 선택한 앱의 새 알림에서 결제 내용을 읽습니다. 선택하지 않은 앱의 알림 내용을 보관하지 않습니다.
  • 앱 목록: 자동 기록 대상을 선택할 수 있도록 기기의 실행 가능한 앱 이름과 패키지 식별자를 조회합니다. 전체 앱 목록을 운영자 서버에 전송하지 않습니다.

결제로 인식되지 않은 메시지와 인증번호 등으로 인식되는 메시지는 가계부 수신 내역으로 저장하지 않습니다. 자동으로 기록된 내역은 원문을 남기지 않으며, 확인 대기 내역은 검토를 위해 원문을 보관합니다. 사용자가 해당 내역을 기록하거나 ‘무시’ 처리하면 저장된 원문을 비우지만, 금액·가맹점·수신 출처·처리 상태 등의 수신 이력은 남습니다.

원문 보관과 백업: 확인 대기 원문에는 자동 만료 기간이 없습니다. 처리 전에 만들어진 백업에는 원문이 포함될 수 있으며, 이후 앱에서 원문을 비워도 과거 백업 내용까지 변경되지는 않습니다.

4. 백업과 Google Drive

기기 내부 백업과 파일 내보내기

앱은 거래·자산·분류·결제수단·정기 및 할부 내역, 알림·SMS 수신 이력, 일부 화면 및 월 시작일 설정을 백업합니다. 내부 백업은 기기 보안 저장소의 키로 암호화합니다. 사용자가 백업 파일을 내보내면 별도로 입력한 백업 비밀번호로 암호화하여 Android 파일 선택 화면에서 지정한 위치에 저장합니다.

저장 위치로 다른 클라우드 서비스를 선택한 경우 해당 서비스에 백업 파일이 전달될 수 있습니다. 이때 파일 보관과 삭제에는 사용자가 선택한 서비스의 정책 및 설정도 적용됩니다.

선택적 Google Drive 백업

사용자가 Google 계정을 연결하고 Drive 백업 비밀번호를 설정하면, 해당 계정의 앱 전용 숨김 공간에 암호화된 백업을 저장합니다. 앱은 이 전용 공간을 이용하는 권한만 요청하며, Drive의 일반 문서·사진 등 전체 파일에 접근하는 권한을 요청하지 않습니다.

연결 후 ‘드라이브에 자동 백업’이 켜져 있으면 데이터 변경 시 하루 1회를 목표로 백그라운드 업로드를 수행합니다. 최초 연결 시 이 설정은 기본적으로 켜져 있으며, 사용자가 끌 수 있습니다. 기기와 네트워크 상태에 따라 실행 시점은 달라질 수 있습니다.

백업 내용은 기기에서 암호화한 뒤 Google로 전송합니다. 백업 비밀번호 자체는 저장하지 않고, 자동 백업을 위한 암호화 키를 기기의 보안 저장소를 이용해 보호합니다. 운영자는 사용자의 백업 비밀번호나 복호화 키를 전달받지 않습니다.

백업의 파일명, 시각, 크기, 임의 기기 구분값, 기기 모델명, 파일 검증값, 암호화 키 구분값 등 관리 정보는 암호화된 본문과 별도로 Google Drive에 전달됩니다. 이 정보는 백업 목록 표시, 기기별 보관 관리 및 파일 검증에 사용됩니다.

5. 외부 서비스 및 국외 처리

앱의 Google 인증·Drive 백업·공휴일 조회 요청은 운영자의 별도 서버를 거치지 않고 각 제공자의 서비스로 전달됩니다. 각 기능에서 이용하는 외부 서비스는 다음과 같습니다.

  • Google 인증·Google Drive: 계정 인증, 권한 관리와 사용자가 선택한 암호화 백업의 저장·조회·복원·삭제에 사용합니다. 관련 데이터는 인증 또는 백업 요청 시 네트워크를 통해 Google로 전달됩니다.
  • 공공데이터포털 공휴일 API: 달력과 날짜 계산에 필요한 공휴일 정보를 조회합니다. 조회 연도와 서비스 인증정보 등을 전송하며, 가계부 거래·메모·문자 원문은 전송하지 않습니다. 통신 과정에서 서비스 제공자에게 접속 IP 등 접속 정보가 전달될 수 있습니다.
  • Gmail: 운영자가 문의 이메일을 수신하고 답변하는 데 사용합니다. 사용자가 보내는 이메일과 첨부 자료는 Google의 메일 서비스에서 처리·보관됩니다.

Google은 전 세계 서버에서 서비스를 제공하므로 Google 인증·Drive·Gmail 이용 정보가 대한민국 외의 국가에서 처리될 수 있습니다. Google의 처리 방식과 보관·삭제 기준은 Google 개인정보처리방침에서 확인할 수 있습니다. 앱은 Google 인증·백업에 필요한 계정 및 접속 정보를 처리하지만, 그 정보를 운영자의 광고·사용자 행동 분석에 이용하지 않습니다.

Drive 연결을 선택하지 않거나 연결을 해제해 이후 백업 전송을 중단할 수 있습니다. 이미 보관된 백업 파일은 별도로 삭제해야 합니다. 선택 기능을 이용하지 않아도 수동 가계부 기록을 사용할 수 있습니다.

6. 보관 기간과 파기

  • 기기의 가계부·설정·수신 이력: 사용자가 앱 데이터를 삭제하거나 앱을 제거할 때까지 보관합니다. 개별 기록의 수정·삭제는 제공되는 앱 기능을 통해 처리합니다. ‘사용 중지’ 또는 복원 가능한 자산 계좌의 ‘삭제’는 원본 데이터의 영구 삭제를 뜻하지 않습니다.
  • 확인 대기 문자·알림 원문: 해당 내역을 기록하거나 무시 처리할 때까지, 또는 앱 데이터를 삭제할 때까지 보관합니다. 처리 완료 후에도 수신 이력의 원문 이외 정보는 남습니다.
  • 기기 내부 백업: 새 백업을 만들 때 일반 백업의 최근 7개를 유지하도록 이전 파일을 정리합니다. 복원 전 안전 백업은 별도로 보관하고 다음 복원 시 교체합니다. 자동 백업을 끄는 것만으로 기존 파일이 삭제되지는 않습니다.
  • Drive 백업: 새 업로드가 확인된 뒤 해당 기기의 최근 10개를 유지하도록 이전 파일을 정리합니다. 업로드가 중단되거나 정리에 실패하면 기존 파일이 남을 수 있습니다. 사용자는 앱에서 백업 파일을 직접 삭제할 수 있습니다.
  • 외부로 내보낸 파일: 사용자가 선택한 저장 위치에 남으며, 사용자가 파일 또는 해당 저장 서비스를 통해 삭제할 때까지 보관됩니다.
  • Drive 연결 정보: 연결 계정과 백업 암호화 키 등의 연결 정보를 기기에 보관하며, 연결 해제 시 제거합니다. 기기 구분값과 일부 사용 설정은 앱 데이터 삭제 시 제거됩니다.
  • 문의 이메일: 발신자 정보·문의 내용·첨부자료·답변 기록은 답변 완료 후 90일 이내 운영자가 관리하는 메일함과 휴지통에서 삭제합니다. 사용자가 더 이른 삭제를 요청하면 요청 처리에 필요한 확인 후 삭제합니다. 법령에 따라 별도 보존 의무가 있는 경우에는 해당 정보와 기간을 안내하고 그 범위에서만 보관합니다.

기기 데이터는 앱 또는 Android의 삭제 기능으로, 백업 파일은 해당 저장 위치의 삭제 기능으로 제거합니다. 서비스 제공자가 운영하는 시스템의 보안·복구용 잔존 데이터 처리에는 해당 제공자의 정책이 적용됩니다.

7. 정보 관리·삭제·권한 철회

사용자는 앱에서 가계부 정보를 열람·수정하고, 제공되는 기능으로 내역을 삭제하거나 암호화된 백업 파일을 내보낼 수 있습니다. 백업 파일은 앱에서 복원하기 위한 형식입니다.

  1. 자동 기록 중지: 앱 설정의 ‘알림 자동 기록’에서 SMS 또는 푸시 자동 기록을 끕니다. Android 설정에서도 앱의 SMS 권한이나 알림 접근 권한을 해제할 수 있습니다. 중지 전에 저장된 내역은 남습니다.
  2. Drive 백업 삭제: 앱 설정 → 데이터 백업·복원 → 드라이브 백업 목록에서 파일을 선택한 뒤 ‘드라이브에서 삭제’를 실행합니다. 다시 생성되지 않게 하려면 자동 백업도 끄세요.
